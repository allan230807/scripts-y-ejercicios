## 🛠️ Contenido del Repositorio

A continuación se detalla cada script disponible en este repositorio y su funcionalidad:

| Script | Descripción / Funcionalidad | Conceptos Clave Aplicados |
| :--- | :--- | :--- |
| 🂡 **`blackjack.py`** | Juego interactivo de Blackjack en consola contra la terminal (Dealer) usando un mazo clásico. | `random`, `time`, listas, mutación (`pop`/`append`), condicionales y bucles `while`. |
